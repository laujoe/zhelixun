# 浙里寻使用指南

## 桌面离线使用

完整解压后，用 Safari、Chrome 或 Edge 打开根目录 `浙里寻-独立网页版.html`。Mac 与 Windows 各提供一个“离线打开浙里寻”快捷入口，普通使用不需要安装 Node.js。

每次打开或刷新先显示登录页，可以进入演示空间或使用本地账号。账号、研究记录保存在当前浏览器；不同浏览器、不同网址和另一台设备不会自动共享账号或资料。不要在无痕窗口中保存长期研究数据。仅用于评审初始状态检查时，可以使用临时浏览器配置或无痕窗口。

Mac 脚本默认打开 Safari，Windows 脚本默认打开 Edge。已有资料在其他浏览器的用户请直接选择原浏览器打开 HTML，不要因为更换入口而误以为资料丢失。HTML 文件名保留历史名称；移动文件、修改名称、切换浏览器或清理浏览器存储前，先导出研究 JSON。

## 首页的两个入口

- **开启全新研究**：围绕一个研究问题，新建项目后进入“提出问题 → 分析问题 → 解决问题”。
- **进入研究平台**：进入智能选库与工具平台，查找数据库、管理项目和研究资料；需要继续已有项目时，在研究工作台选择项目。这个入口不要求已经存在项目。

## 研究流程

1. 进入演示空间或本地账号，选择“开启全新研究”，填写项目名。
2. 按“提出问题 → 分析问题 → 解决问题”推进，在各阶段添加笔记、网址、附件和引用。
3. 输入研究问题，使用“离线寻找数据库”匹配已内置的公开数据库目录。离线匹配不需要模型服务。
4. 数据库卡片提供资源入口和官方访问说明。实际全文与访问权限由学校或资源方决定。
5. 完成研究后，可在工作台继续整理项目、任务与资料，或导出研究档案。

本地账号和学号字段不构成校园身份验证。浙大学生试用可由团队线下邀请；本版本没有自动邀请码校验、邮箱验证码和学校认证接口，不采集学校账号密码。只有在学校或资源方官方页面登录学校账号。

## 在平台中打开已有研究

进入平台后，点击侧栏项目名称，或进入“研究工作台”后选择项目。已有项目都会先打开工作台；“演示项目”“12”“23”等只是不同项目的名称。

项目详情始终提供研究入口：

| 项目状态 | 操作 |
| --- | --- |
| 未开始研究 | 点击“开始研究”，在这个项目中进入提出问题，保留已有资料 |
| 进行中 | 点击“继续研究”，进入上次保存的阶段，继续读取该项目的资料与本机草稿 |
| 已完成研究 | 点击“查看研究过程”；回看和切换阶段不会改写完成状态 |

也可点击工作台上方“新建或继续研究”，选择已有项目或创建新项目。普通项目开始研究不会另建副本。“资料阶段”标签仅筛选工作台资料；要进入研究页面，请使用项目的研究按钮。

研究页点击“返回项目工作台”后，会回到同一项目。侧栏加号可先建立资料项目，保存后进入该项目工作台；首页“开启全新研究”则在创建后直接开始三阶段研究。

## 备份与多端接续

1. 先保存当前笔记、研究输入及其他记录。草稿只用于本机恢复，不包含在研究备份中。
2. 进入“导出与备份”，点击“备份当前完整项目”。该入口忽略之前的关键词和日期筛选，包含项目及附件原件。
3. 确认 JSON 已下载，再通过 AirDrop、个人文件传输或已有网盘传送到另一设备。
4. 在另一设备打开程序，进入本地账号，选择 JSON，核对项目、记录和附件预览后导入。

默认安全导入会跳过一致内容；有冲突时保留完整副本。主动选择“更新已有记录”会列出将覆盖的标题，确认后更新；“导入副本”总是创建副本。备份中没有的本机记录不会自动删除。同一项目建议轮流使用设备，减少分支冲突。

“最近生成备份”表示程序生成过文件，不保证系统已完成下载。浏览器内恢复点不能替代外部 JSON。把程序 HTML 放进网盘只会传递程序，不会自动同步浏览器中的研究资料。

单个附件最大 10 MB，单份 JSON 备份和导入最大 100 MB。CSV 不包含附件原件，完整恢复请使用 JSON。TXT / Markdown 采用 UTF-8；程序读取前 100000 字符供查阅，附件原件完整保留。超过单份备份限制时，按项目或记录范围分批备份，并逐份核对。

## 手机与可安装的静态网页

执行 `npm run build` 后，`dist/web/` 包含可用于静态托管的网页文件。将其中 `构建清单.json` 列出的程序文件发布到支持 HTTPS 的静态站点即可；无需维护应用服务器、数据库或邮件服务。不要上传整个源码工作目录、`.local/` 或个人研究 JSON。

手机使用系统浏览器访问固定网址，可按浏览器支持情况添加到主屏幕。首次访问需要联网并完成缓存；缓存成功后可离线打开程序。学校数据库和外部资源仍需要联网及相应访问权限。更新提示出现后先保存记录，再主动确认更新。

静态网页使用离线选库，无法调用电脑上的本机模型配置。安装到桌面或主屏幕不产生云同步，跨设备仍使用 JSON。手机文件预览器不一定能运行完整离线 HTML，因此手机优先使用静态网址。当前交付没有公网部署，也没有预设网址。

## 可选在线模型

仅在需要使用自己的模型接口时启用。安装 Node.js 22 或更新版本后：

- Mac：双击 `scripts/launchers/启动浙里寻.command`。
- Windows：双击 `scripts/launchers/启动浙里寻.cmd`。
- 终端：在项目根目录运行 `npm run open`；或运行 `npm start` 并保留终端。

启动器会构建程序、仅在本机 `http://127.0.0.1:4173` 运行，并打开浏览器。同一目录重复启动会复用服务；源码变化时会更新受启动器管理的服务。端口被其他程序占用时会提示，不会自动关闭其他程序。

Mac 双击脚本受阻时，可使用根目录的 `npm run open` 命令；普通离线使用仍可直接打开 HTML。启动日志写入 `.local/server.log`。关闭网页不会停止本机服务；用 `npm run stop` 或同目录的“停止浙里寻”入口停止。`npm start` 前台运行时，在原终端按 Ctrl+C。

在“账号设置 → 在线模型”开启功能，填写支持 Chat Completions 的兼容服务地址、模型名及自己的 API Key。地址不要包含 `/chat/completions`。模型名称和可用性以用户所选服务为准。连接测试与研究请求均可能消耗该服务的额度。

密钥默认仅在本机服务内存中使用。勾选“在本机记住密钥”才写入 `.local/models/`；不要分享该目录。浏览器只保存随机配置凭据，研究 JSON 不包含模型配置。“清除配置”会删除对应已记住的密钥。在线请求最多发送最近 40 条对话与用户勾选的 20 份文本资料，每份最多 10000 字符；不自动发送附件原件，不自动抓取网址全文。

本地 `file://` 文件和 `http://127.0.0.1:4173` 的浏览器存储不互通。启用本机服务前，先在原页面导出 JSON，再在新地址的本地账号中导入。模型关闭、断网或接口失败时，可以使用离线选库。
