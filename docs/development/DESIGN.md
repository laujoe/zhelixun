# 浙里寻 Design System

## Overview

### Creative North Star

深空里的研究工作台：蓝紫空间承载信息，粉色与暖金色在页面中下部形成清楚的光色过渡，浅薰衣草白卡片承担阅读和编辑。

### Product context and register

- 受众是整理研究问题、数据库和材料的中文个人研究者，界面为简体中文。
- 登录和双行星入口偏品牌表达；目录、研究、备份、设置偏工具使用，任务清晰优先。
- 配色令牌见本文件与 `src/styles.css`；`style/choose_background_final.png` 用于入口，`style/reg_background.jpg` 用于登录。
- 品牌形象为企鹅宇航员：`style/penguin_icon.png`（256px，favicon 与全部 `brand-mark`，经 `--brand-icon` 变量内联一次）。
- 探索模式（研究航程）为全屏沉浸页，不入侧栏外壳。三个阶段（提出问题/分析问题/解决问题）各配背景：`--question-texture`（`style/question_background.jpg`）、`--nebula-texture`、`--arrival-texture`（与入口页共享）。底部为企鹅“小寻”头像加气泡（引导语、打字动画、结果汇报），数据库结果以浅色气泡卡片进入对话流。动效：气泡弹入、企鹅漂浮、星星闪烁，`prefers-reduced-motion` 下全部关闭。
- 标志性元素是以 `style/nebula_reference.jpg` 为纹理、边缘柔化的双星云选择。工作区星点保持低亮度，避免影响阅读。选择标题和提示文案居中叠放于各自星云内部，以深色柔和衬底和文字阴影保证可读。
- 避免大面积暖卡其与冷紫生硬拼接、过亮的金色按钮正文区域、密集星点与持续漂浮动画。
- 令牌采用 Model B：`src/styles.css` 最后的 Canonical theme 块为运行时唯一权威，此文镜像其值。共享组件直接消费 CSS 变量；构建仅嵌入源码与图片。

## Colors

`--space` / `--space-violet` 为背景；`--sky` / `--violet` / `--pink` / `--gold` 组成 `--spectrum`。渐变保留在星空背景、品牌与研究阶段装饰中。常规主要按钮使用克制的实色紫 `#61509f`，保持白字可读；卡片蓝粉金过渡降低饱和度。

`--surface` / `--surface-raised` / `--surface-soft` 区分卡片、输入和次级区域；`--ink` / `--muted` 用于浅色表面，`--on-space` / `--space-muted` 用于深色外壳。错误和成功有文字说明，不仅依赖颜色。

## Typography

正文使用中文无衬线回退栈，标题沿用宋体风格，技术说明使用等宽字体。登录副标题固定20px等宽。保持现有紧凑工作区字号和自然中文换行，不引入远程字体依赖。

## Layout

桌面侧栏246px；1200px以下使用抽屉。导航按钮始终显示，宽屏可主动收起侧栏。主区域最大1440px；800px以下的内容容器在问题和结果之间切换。登录卡片桌面为 `clamp(360px,33.333vw,520px)`；680px以下铺满扣除32px边距。入口背景始终 `center bottom / cover`，选择球体680px以下纵向排列。

## Elevation & Depth

工作卡片用细边框和轻阴影分层；背景有柔和光晕。原生dialog进入顶层，使用深蓝透明遮罩和轻模糊；不以阴影替代边框与焦点。

## Shapes

卡片14px、对话框18px、控件8px圆角。球体使用圆形与径向光照，其周围少量星点为纯装饰。

## Components

### Foundational visual states

共享Button覆盖悬停、按下、键盘焦点、选中、禁用和处理中状态；键盘焦点使用2px紫色轮廓，浅色面板用较深紫，深色外壳用浅紫；去掉原有粗粉色光圈。禁用状态保留说明文字。滚动条由全局CSS定义thumb、track、hover、active及forced-colors回退。

### Buttons and actions

主要操作使用实色紫底；普通操作为浅色表面与细边框，辅助操作为透明背景。共享尺寸令牌：桌面 `--control-height:40px`、`--control-compact-height:32px`、`--control-radius:8px`、`--control-font:12px`；680px及以下两种高度均为44px、按钮字号13px、表单字号16px。常规图标16px，纯图标按钮按所在尺寸档保持正方形。分段切换内按钮32px，外容器40px；移动端内按钮44px。禁止各页面再次使用24/29/31/36/37px等零散控件高度。危险操作使用独立错误色。等待时保留按钮尺寸，不自动重试在线调用。

### Navigation and data display

工作台项目选择器旁提供“新建或继续研究”，复用现有共享 dialog；取消返回原页面。侧栏项目统一打开工作台。项目详情以现有主按钮承载“开始研究／继续研究／查看研究过程”，标题附近以轻量文字显示状态；编辑、导出、删除保持普通操作样式。资料阶段筛选前标明“资料阶段”，与研究入口区分。数据库卡、收藏、研究结果复用ResourceCard。初始说明位于问题面板下方，实际结果位于桌面右侧。

### Forms and overlays

复用Field、AutoTextarea与Modal。原生select/date接受系统弹出界面。select收起时移除平台默认外观，使用统一高度、内边距和单一向下箭头；强制颜色模式恢复系统箭头。智能选库的“模型设置”与选库方式并排，是轻量辅助入口，直接打开原有账号设置页；不单独占据整行。命名框复用原生dialog，输入自动获得焦点，Escape或取消恢复行星及触发按钮焦点；空名称保留表单并显示错误。文本框自动增长且不可拖拽缩放。

### Iconography

沿用项目已打包的线框图标，15–18px常规尺寸；含义不明确的操作附文字或可访问名称。

### Motion

登录页品牌、标题、表单依次淡入上升，延迟分别为0、80、160ms，复用content-rise和共享动效令牌；减少动态效果时关闭。

悬停150–250ms，星云入口850ms从下方升起，命名框380ms淡入上移。结果面板和共享内容卡片使用content-rise，运行时CSS令牌--reveal-duration为480ms、--reveal-step为55ms、--reveal-distance为22px；卡片逐个进入，延迟最多11步。尊重prefers-reduced-motion，关闭进入动画。工作页无持续背景动画。

### Content and data visualization

使用直接的中文操作词，保留既有三阶段完成按钮文案。数据库名称、链接及研究资料以真实现有数据为准。

## Do's and Don'ts

- Do: 新页面复用语义令牌和共享组件。
- Do: 在390、862、1183及宽屏核对深浅表面文字对比。
- Don't: 为单页重新复制独立配色或弹窗行为。
- Don't: 在研究文本背后叠加高亮星点或花纹。

### Research layout

输入区不再重复呈现模型回复或结果汇报气泡，回复仅进入对话流，处理中显示简短状态。智能选库初始问题面板占满内容宽度，出现结果后恢复原有分栏；窄屏沿用问题/结果切换。个人标签复用浅紫色与主紫色边框突出显示，按钮支持键盘编辑和删除。探索数据库收藏复用卡片内按钮，按当前项目及研究阶段保存。

三阶段对话及本阶段资料位于左栏，候选数据库位于右栏；1000px以下依次纵向排列。阶段完成按钮保留既有外观与页底位置。全站背景使用CSS的--cosmic-background，浅色卡片使用--surface-wash；粉金过渡不依赖滚动到长页面底部才能看见。


### 3.2.5 操作按钮规范

操作按钮使用一个前置线性图标和一个可见文字标签。共享 Button 和 Link 保持同一图文顺序，图标通常为 16px、线宽 1.7，数据库卡片中为 15px。图标仅作装饰，对读屏隐藏；原有无障碍名称保留。使用现有内置图标，不增加字体或网络图标依赖。

常规操作高 40px，紧凑操作高 32px，手机触控区域不低于 44px。圆角沿用 8px，图文间距 6–7px；普通字重 500，主要操作 600。关闭、删除、帮助、导航等原纯图标操作补可见短标签。内容标题、项目卡片和日期选择保留各自内容结构；背景遮罩和系统文件选择器不套用操作按钮排版。

数据库卡片第一行是数据库说明、收藏和标签，第二组是打开资源、当前页打开、官方访问说明和复制链接。打开资源用浅紫底表达优先级，其余访问操作用低强调样式，统一高度和文字尺度，不使用下划线和超小字号。窄卡片访问操作为两列，容器宽度达到 490px 时为四列。收藏选中、悬停、键盘焦点和禁用状态须可辨认；多个资源卡片保持同一按钮规则。

图标加入后仍须检查 320、390、862、1183、1440px；特别关注项目阶段筛选、顶部导航、弹窗、长标题和资源操作区的换行。


### 3.2.6 数据库卡片层次（替代上一节卡片操作排布）

卡片阅读顺序为标题、摘要、只读分类、主次操作、辅助操作。标题 18px／600，摘要 12px、1.85 行高且最多三行，语言／类型与分类标签为 10px。只读分类不使用按钮式描边；个人可编辑标签仍保留按钮外观。卡片浅色底不叠加渐变，资源标记使用浅色弱强调。

第一排并列“数据库说明”和“打开资源”，前者为描边次按钮，后者为唯一紫色实色主按钮。第二排放收藏、标签和“更多”；更多采用原生 details/summary，展开三项低频访问操作，不遮挡其他卡片。Enter／Space 可展开，Escape 关闭并恢复 summary 焦点。详情弹窗内三个访问选项保持直接展示。

按钮继续使用前置小图标＋文字，常规高度 40px、紧凑高度 32px，手机至少 44px。新增规则只作用于资源卡片及其详情访问区域。


### 08 版双区整理（当前数据库卡片规范，3.2.8 修订）

以用户选定的 08 版设计稿为准：浅色内容卡，书面标题，细分隔线，左侧为阅读与访问，右侧为收藏与整理。卡片保留原星空背景上下文，移除单字装饰块和重复标题图标。标题仍能打开原数据库说明。

- 卡片底色 `#fdfcfe`，12px 圆角；标题 22px，摘要 13px，元数据及分类 11px。手机标题 20px。
- 操作图标 14px、描边 1.65px，文字 12px、中等字重。说明为纯图文；打开资源为 `#eeebf8` 淡紫底与 `#53427e` 文字，紧凑胶囊；收藏、标签、更多为透明底。
- 两组使用各自内容宽度，宽卡片由空白分隔并分居左右；不把按钮拉伸为相等宽度。卡片内容宽度不超过 400px 时，两组换行，保持组内顺序。
- 目录网格按至少 440px 的卡片目标宽度自动分列，屏幕更窄时占满一列。同排卡片使用网格拉伸保持等高，底部操作区以自动上边距贴齐底部，分隔线与操作按钮同时对齐。行高由该排内容决定，单列时保持自然高度；更多菜单为浮层，不改变行高。
- 桌面操作高度 32px。手机点击区域保持 44px，打开资源的淡色底在触控区域内部留白，保持视觉轻量。
- 更多采用原生 details 入口和绝对定位浮层，卡片焦点时提升层级；选择可用空间更充足的方向，限制菜单高度并允许内部滚动。外部点击、焦点离开、窗口缩放或外部滚动关闭；菜单内部滚动不关闭。Escape 收起并回到入口。
- 不引入组件库。增加三个小型内联图标以匹配 08 稿；Star 沿用已有 Lucide 0.468.0 的 ISC 授权，标签及更多为基础矢量图形。


### 3.2.9 · 背景与卡片分隔规则

项目文件夹、检索留痕和研究日历中的记录列表以卡片与间距分隔，不在列表顶部额外画贯穿背景的横线。资料阶段筛选栏保留原有底部留白，移除下边框，避免与首张圆角卡片形成双线或伸出的直角线。卡片自身边缘、数据库操作区、弹窗及表单内的分隔线继续保留；不修改全局 `--line` 色值与 `hr` 规则。


数据库筛选区与研究阶段的资料条目同样用留白分区。任务看板采用 48px × 2px 的渐隐短线，沿用各列的低饱和颜色；旧版会话资料分区保留 64px × 1px 的淡色渐隐线。标记用 CSS 伪元素绘制，不占满整列、不承载状态文字、不参与交互，也不改变键盘焦点。数据库卡片内的细线、表单与弹窗边框仍用于明确功能分区。
