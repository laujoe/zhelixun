# UX Contract

## Product context

中文个人研究工作台，支持离线使用、当前浏览器保存及用户自选模型。产品说明见根目录 README.md；本文件记录现有交互约定。无障碍目标为 WCAG 2.2 AA，不表示已经完成符合性认证。

## Visual contract

DESIGN.md记录视觉意图。src/styles.css的Canonical theme块拥有运行时令牌；共享组件消费令牌，独立HTML由构建生成。当前支持单一星际主题和系统强制颜色回退。

## Navigation and responsive behavior

- 每次打开或刷新网站先显示登录页，保留账号及研究记录，各页面独立登录且不会互相登出；同步记录保留本页身份。登录成功后进入双星云入口。入口：左侧“开启全新研究”打开居中命名 dialog，同时隐藏两个行星，创建项目后进入问题研究流程；右侧“进入研究平台”进入智能选库与工具平台，不要求已有项目，也不自动续接某个项目。
- 命名：自动聚焦输入；空名称显示错误；取消、关闭或Escape恢复两个行星及新研究按钮焦点。
- 导航：按钮在所有宽度可见；1200px以上默认常驻侧栏，可收起；以下为带遮罩、焦点限制与Escape关闭的抽屉。
- 侧栏项目与项目概览卡片统一打开该项目工作台，并复位到项目内容视图；项目状态不再决定这两个入口的页面跳转。工作台下拉框切换项目时保留当前文件夹、看板或日历视图。
- 项目详情始终提供“开始研究”“继续研究”或“查看研究过程”，由 `getResearchState` 统一解析。状态文字同步用于项目概览和共享弹窗。资料阶段标签只筛选材料，选中按钮使用 aria-pressed。
- 工作台项目选择器旁的“新建或继续研究”打开共享 dialog，支持继续已有项目和开启全新研究；默认选中当前项目，否则首个项目。没有项目时默认新建并禁用继续选项。取消保持原页面和焦点。
- 进入已有研究统一经过 `beginResearch`：普通项目在原 ID 上初始化，历史研究缺字段时按有效研究记录恢复；进行中和已完成项目不重复写入。不因浏览、切换项目或登录执行批量迁移。
- 已完成研究使用页面内的临时阶段进行回看，打开、切换和返回不改写项目阶段、完成标记和更新时间；研究页可继续按既有能力整理资料。研究页明确提供“返回项目工作台”，返回同一项目。
- 从其他平台页面使用侧栏加号创建普通项目，保存后打开新项目工作台；首页开启全新研究依然创建并直接进入提出问题。
- 各研究阶段共用的添加内容菜单仅提供研究材料、研究笔记、引用证据和研究图表。文件夹页签为全部内容及三个研究阶段；移除待归档、图表、项目资源页签，既有内容仍在全部内容中读取。
- 任务看板合并为待完成与已完成两栏；旧inbox、research均显示为待完成，编辑时统一为inbox，不批量改写历史数据。桌面两栏，沿用main内容容器799px及以下一栏的规则。
- 三阶段资料位于对话下方，候选数据库位于右栏，小屏先对话和资料、再候选数据库。完成按钮仍在页底，完成最终阶段后返回研究工作台。研究探索页同时挂载共享弹窗和通知，支持添加、编辑、查看及删除资料。
- 选库方式旁的“模型设置”进入既有账号设置页，不改变选库方式、草稿和项目归属；常规控件与辅助按钮分别消费共享尺寸令牌，手机触控区域至少44px。
- 选库：初始说明卡在问题表单下方；桌面实际结果在右侧。内容容器小于800px沿用问题/结果切换。
- 目录按24条“继续显示”，搜索与筛选保留既有本地状态策略；不把敏感研究问题写入URL。

## Overlays and feedback

原生dialog由ZLXUI.Modal统一拥有，提供顶层遮罩、标题、焦点管理、Escape及焦点恢复。提示使用App.notify；表单错误保留输入，使用可见错误文字。删除、恢复及清除数据沿用既有确认流程。

## Async and resilience

在线功能开关、账号隔离、密钥处理、取消、超时、重试和离线恢复沿用已实现逻辑。视觉变更不更改模型API或研究数据结构。材料和对话继续按现有账号及项目存储。

## Verification

- 智能选库草稿、标签及结果在同一登录会话内跨页面保留；无结果时输入区铺满内容宽度，返回结果后使用既有响应式分栏。
- 检索留痕类型选项与添加内容菜单共享 CONTENT_CHOICES；历史记录在全部类型中保留。
- 个人标签在卡片标签栏突出显示，点击打开共享标签编辑弹窗，支持编辑和删除，官方标签只读。
- 探索结果通过卡内收藏按钮按项目与阶段独立收藏；工作台三个阶段可读取收藏，重新加载和备份导入保留归属。
- 输入区不重复显示模型回复，回复仅在对话流呈现；等待请求时在输入区显示简短状态文字。
