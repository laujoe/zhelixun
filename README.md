# 浙里寻

浙里寻是一个以“提出问题 → 分析问题 → 解决问题”组织资料的个人研究工作台。包含 394 项数据库目录及对应说明，支持项目、笔记、网址、附件、收藏、任务和研究档案导出。研究资料保存在使用者的浏览器中，跨设备通过 JSON 备份手动接续。


## 快速体验

**无需安装 Node.js，无需配置服务器或 API Key。先完整解压 ZIP，再打开网页。**

| 系统 | 推荐入口 |
| --- | --- |
| macOS | 双击 `离线打开浙里寻.command`，默认使用 Safari；或右键根目录 HTML → 打开方式 → Safari / Chrome |
| Windows | 双击 `离线打开浙里寻.cmd`，使用 Edge；也可右键 HTML 选择已安装的浏览器 |
| 其他桌面系统 | 使用现代浏览器打开根目录 HTML |

若 Mac 阻止脚本或 HTML 被文本编辑器打开，直接通过“打开方式”选择浏览器即可。无需修改系统安全设置。原数据在 Chrome 中的使用者请继续使用 Chrome，或先导出 JSON 再迁移。

进入页面后，点击“进入演示空间”即可查看功能，也可创建本地账号。建议体验：新建研究项目 → 添加笔记或附件 → 离线寻找数据库 → 推进研究阶段 → 在“导出与备份”生成完整项目 JSON。演示空间是功能演示入口，不代表学校身份认证。

## 文件怎么找

```text
zhelixun-github/
├── README.md                      项目介绍与使用入口
├── 浙里寻-独立网页版.html    可直接打开的完整离线程序
├── 离线打开浙里寻.command / .cmd   Mac / Windows 离线入口
├── package.json                   构建、测试与打包命令
├── src/                           应用源码、公开数据、内置运行依赖
│   └── data/source/               数据库说明的原始公开资料及来源
├── style/                         实际使用的 5 张图片
├── scripts/                       构建、打包、数据导入、可选本机服务
│   └── launchers/                 可选模型服务的启动 / 停止入口
├── tests/                         自动测试和虚构测试资料
├── docs/                          使用、开发、提交说明及第三方声明
│   └── development/               现有视觉与交互规范
└── 文件校验清单.json               比赛 ZIP 内各文件的 SHA-256
```

开发目录还可能有 `dist/`（生成产物）和 `.local/`（本机配置与私人归档）；它们已列入 Git 忽略规则，也不进入比赛源码 ZIP。需要比赛提交包时，使用 `dist/submission/` 中生成的 ZIP。

## 上传 GitHub

这个公开副本已清除资源目录中两项服务的明文共享账号和密码，访问说明统一引导至官方入口；独立 HTML 已从清理后的源码重新生成。系统杂项文件已排除，图片 EXIF 已移除，未附带 Git 历史或本机模型配置。账号、学号和密钥的功能字段以及虚构测试数据仍用于正常功能与测试。

将此目录内的源码文件作为仓库根目录上传，并包含 `.gitignore`。提交前查看待提交文件列表；本机模型设置、私人研究备份、浏览器配置和测试截图不要放进源码目录或已跟踪的文件。可将私人导出统一放在已忽略的 `exports/` 中。

通过 Git 提交时，提交作者名称和邮箱来自 Git 配置，不属于源码清理范围；如需隐藏邮箱，请使用你自己的 GitHub 隐私邮箱。发布仓库从清理后的源码建立，不包含开发工作目录的历史提交。

第三方许可声明和资料来源予以保留；原创代码和图片沿用原有权利状态。本次整理没有新增开源许可证。

## 源码构建与验证

在解压目录中使用 **Node.js 22 或更新版本**。构建和核心测试使用 Node 内置模块，不需要运行 `npm install`。

```sh
npm test         # 自动测试；本机端口需可用，不调用真实模型
npm run build    # 更新离线 HTML，并生成 dist/web/ 静态网页
npm run package  # 重新构建并生成 dist/submission/比赛源码 ZIP
```

Git 仓库不跟踪生成的 `文件校验清单.json`；从仓库克隆后先运行 `npm run package` 生成校验清单，再执行 `npm run verify`。交付 ZIP 中附带的清单用于校验解压时的原始文件；修改源码或重新导入数据后，应重新打包。`npm run package` 会生成新 ZIP，并刷新工作目录的校验清单；此后可再次执行 `npm run verify`。可选浏览器测试需另行提供 Playwright 和浏览器，详见开发说明。
